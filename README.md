# OpenStudio

A free, open-source (GPLv3) digital audio workstation in Rust, aiming for workflow familiarity
and project-file compatibility with FL Studio. Windows first; Linux/macOS later.

OpenStudio is an independent clean-room reimplementation. It contains no code, artwork, or other
assets from FL Studio and is not affiliated with or endorsed by Image-Line. "FL Studio" is a
trademark of Image-Line Software.

Status: pre-alpha — foundations (project file format) in progress.
